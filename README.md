# Batu Saribay

Security and systems programming, mostly in Rust. I build small,
keyboard-first command line tools and document them like manuals.

Everything lives at **[batusaribay.github.io](https://batusaribay.github.io)**:
projects, demo recordings, the agent guidelines I work by, the README template I
use, and contact details.

## Projects

- [calc](https://github.com/batusaribay/calc) - evaluate arithmetic expressions
- [deepseek-chat](https://github.com/batusaribay/deepseek-chat) - chat with DeepSeek
- [dictionary](https://github.com/batusaribay/dictionary) - offline dictionary lookups
- [email](https://github.com/batusaribay/email) - email over IMAP and SMTP
- [music-player](https://github.com/batusaribay/music-player) - search and play music from a local library or YouTube
- [news](https://github.com/batusaribay/news) - read news articles
- [otw](https://github.com/batusaribay/otw) - OverTheWire games
- [saturn-art](https://github.com/batusaribay/saturn-art) - render ray-traced Saturn
- [web-search](https://github.com/batusaribay/web-search) - search the web
- [wiki](https://github.com/batusaribay/wiki) - read Wikipedia
